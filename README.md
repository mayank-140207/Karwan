# Karwan

Karwan — A real-time, community-verified trust layer for safe and adaptive domestic travel.

---

## Overview

Karwan provides an authentic, ground-truth verified domestic travel experience across India. Combining local intelligence, community accountability, and adaptive journey tracking, Karwan empowers travellers to explore with confidence and local trust.

---

## Core Modules

1. **LiveTrail**: Real-time transit monitoring and dynamic waypoint tracking that keeps travellers informed of route conditions, transit timings, and real-world safety updates.
2. **TrustRadar**: Community-verified safety and confidence scoring, providing situational awareness and verified local recommendations for destinations and transit points.
3. **Auto-heal**: Intelligent, dynamic itinerary recalibration that suggests alternate verified routes, stays, and experiences when unforeseen disruptions occur.
4. **Ground Truth**: A directory of community-audited, verified local stays, guides, and artisan vendors backed by KARWAN ID credentials.

## Getting Started

### Prerequisites

* Node.js (v18 or higher recommended)
* npm or pnpm

### Installation and Execution

1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure environment variables:
   Copy `.env.example` to `.env` and set your credentials:
   ```bash
   cp .env.example .env
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Build for production:
   ```bash
   npm run build
   ```
